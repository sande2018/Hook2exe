# ════════════════════════════════════════════════════════════
#  Hook2Exe 依赖说明（requirements.txt）
# ════════════════════════════════════════════════════════════
#
# 【核心结论】生成器核心功能 100% 基于 Python 标准库，
#            无需安装任何第三方包，直接运行：
#
#                python hook2exe.py
#
# ────────────────────────────────────────────────────────────
# 实际使用的标准库模块（Python 3.8+ 自带）：
#
#   argparse            命令行参数解析
#   hashlib             网址哈希（数据目录隔离 / 互斥量命名）
#   html                网页标题/图标链接的实体反转义
#   io                  图标图片内存读写
#   math                默认图标的抗锯齿圆渲染
#   os / shutil         文件与目录操作、DLL 拷贝
#   re                  油猴元数据与 HTML 解析
#   struct / zlib       纯 Python ICO/PNG 编码（无 Pillow 回退）
#   subprocess          调用系统 csc.exe 编译生成的 exe
#   sys / tempfile      进程与临时编译目录
#   threading / queue   GUI 后台构建线程与日志队列
#   tkinter             图形界面（Windows 官方 Python 自带）
#   urllib.parse / urllib.request   favicon 与网页标题抓取
#
# ────────────────────────────────────────────────────────────
# 【可选增强依赖】不安装不影响任何核心功能：
#
# Pillow >= 9.0
#   用途：任意格式图标（png/jpg/bmp/gif）→ 多尺寸 ICO 的转换质量更好；
#        默认字母图标带真实的中文/西文字形渲染。
#   不安装时的回退：PNG 图标直接嵌入 ICO；
#        其余格式抓取失败 → 纯 Python 渐变圆默认图标（已验证可用）。
#   安装：pip install pillow
#
#Pillow>=9.0
#
# ────────────────────────────────────────────────────────────
# 编译/运行时依赖（非 pip，系统级，Win10/11 一般自带）：
#
#   - .NET Framework 4.x（含 csc.exe）   打包机：现场编译生成的 exe
#   - Edge / WebView2 运行时 (x64)       目标机：生成 exe 的浏览器内核
#   - WebView2 SDK DLL ×3                已内置在 lib\ 目录，随应用分发
#
# ════════════════════════════════════════════════════════════
